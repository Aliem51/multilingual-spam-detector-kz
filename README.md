## 📌 О проекте

**Spam Detector Pro** — это дипломный проект, представляющий собой систему фильтрации нежелательной почты и сообщений. В основе лежит модель машинного обучения (CatBoost), обученная распознавать спам на трёх языках: английском, русском и **казахском**. Проект включает в себя обученную модель, REST API для интеграции и удобный веб-интерфейс на Streamlit для одиночной и пакетной проверки сообщений.

## 🛠 Стек технологий

*   **Машинное обучение (ML):** `CatBoostClassifier` (используется как SOTA-решение для классификации табличных и текстовых данных), `scikit-learn` (базовые алгоритмы, такие как Logistic Regression, использовались для сравнения), `nltk` (обработка естественного языка).
*   **Backend / API:** `FastAPI`, `pydantic`, `uvicorn`.
*   **Frontend:** `Streamlit` (интерактивный дашборд и пользовательский интерфейс).
*   **Анализ данных:** `pandas`, `numpy`.
*   **Язык программирования:** Python 3.

## 🎯 Какую проблему решает?

Классические спам-фильтры хорошо справляются с английским языком, однако качество их работы значительно падает при обработке мультиязычных сообщений, особенно на локальных рынках.

**Уникальность данного проекта:**
1.  **Казахстанский контекст:** В открытом доступе **нет готовых датасетов** спама с казахстанской спецификой. В рамках этого проекта был собран уникальный набор данных, включающий реальные мошеннические схемы, актуальные для РК (фишинг от имени Kaspi Bank, eGov, Kcell, OLX, Wildberries и др.), а также легитимные сообщения на казахском языке. Часть данных генерировалась с помощью ИИ, часть собиралась вручную из открытых источников.
2.  **Мультиязычность:** Модель одинаково хорошо распознает спам на кириллице (русский, казахский) и латинице (английский), а также в смешанных текстах.
3.  **Готовое микросервисное решение:** Модель обернута в REST API, что позволяет легко интегрировать ее в любые почтовые клиенты, мессенджеры или CRM-системы.

## 🚀 Как запустить (How to run)

### 1. Клонирование репозитория

```bash
git clone https://github.com/ВАШ_USERNAME/multilingual-spam-detector-kz.git
cd multilingual-spam-detector-kz
```

### 2. Настройка виртуального окружения (рекомендуется)

```bash
python -m venv .venv
# Активация на Windows:
.venv\Scripts\activate
# Активация на Mac/Linux:
source .venv/bin/activate
```

### 3. Установка зависимостей

Убедитесь, что у вас установлен Python (версии 3.8+).

```bash
pip install pandas catboost fastapi uvicorn streamlit scikit-learn nltk
```

*(Опционально: создайте файл `requirements.txt` в вашем проекте для удобства установки)*

### 4. Запуск приложения

В проекте доступно два режима работы: **Web UI** и **REST API**.

#### Запуск Web-интерфейса (Streamlit)
Этот режим запускает интерактивный дашборд, где можно проверить отдельное сообщение или загрузить CSV-файл для пакетной проверки.

```bash
streamlit run App.py
```
*После запуска приложение будет доступно в браузере по адресу: `http://localhost:8501`*

#### Запуск REST API сервера (FastAPI)
Этот режим запускает сервер для программной проверки сообщений.

```bash
uvicorn api:app --reload
```
*API будет доступно по адресу: `http://127.0.0.1:8000`*
*Интерактивная документация Swagger UI: `http://127.0.0.1:8000/docs`*

---

### 📡 Пример использования API (Python)

После запуска сервера FastAPI вы можете отправить POST-запрос для проверки текста:

```python
import requests

url = "http://127.0.0.1:8000/predict"
data = {
    "text": "Сіздің шотыңыз бұғатталды! Құлыпты ашу үшін сілтеме арқылы өтіңіз: http://kaspi-kz-help.com",
    "threshold": 0.5
}

response = requests.post(url, json=data)
print(response.json())
```

**Ожидаемый ответ:**
```json
{
  "is_spam": true,
  "spam_probability": 99.85,
  "verdict": "SPAM DETECTED",
  "threshold_used": 0.5
}
```

## 📁 Структура проекта

*   `App.py` — веб-интерфейс на Streamlit.
*   `api.py` — REST API сервер на FastAPI.
*   `catboost_spam_model.cbm` — обученная модель машинного обучения (CatBoost).
*   `Train_V2_CatBoost.py` — скрипт обучения финальной модели.
*   `train_local.py` — старая версия скрипта обучения (для истории).
*   `perfect_kz_dataset.csv` — уникальный собранный датасет (может отсутствовать в репозитории из-за ограничений размера GitHub, ~108MB).
